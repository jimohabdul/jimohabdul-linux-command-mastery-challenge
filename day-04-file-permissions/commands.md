# Day 4: File Permissions and Ownership

## Commands Covered Today
- `ls -l` - List directory contents in long format to inspect file permissions (e.g., `-rwxr-xr--`), user owner, and group owner.
- `chmod` - Change file/directory access permissions using symbolic modes (e.g., `chmod +x file`) or numeric modes (e.g., `chmod 755 file`).
- `chown` - Change the user and group ownership of a file or directory (e.g., `chown user:group file`).
- `chgrp` - Change specifically the group ownership of a file or directory (e.g., `chgrp groupname file`).

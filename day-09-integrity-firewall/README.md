# Day 9: Integrity, Encryption & Firewalling

## Phase 2 - Permissions, Ownership & Security
This module covers file integrity verification, asymmetric encryption using GPG, filesystem immutability, and basic firewall configuration using UFW.

### Topics Covered
* File integrity verification via checksums (`md5sum`, `sha256sum`).
* Asymmetric encryption and key management (`gpg`).
* Advanced file attributes and immutability (`chattr`, `lsattr`).
* Firewall management and traffic restriction (`ufw`).

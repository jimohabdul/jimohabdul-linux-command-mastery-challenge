# Day 9 Commands Reference

* `md5sum` — Computes or checks MD5 message digests to verify file integrity.
* `sha256sum` — Computes or checks SHA-256 cryptographic checksums for secure file verification.
* `gpg --gen-key` — Generates a new GnuPG key pair for asymmetric encryption and digital signatures.
* `gpg --encrypt` — Encrypts files using a recipient's public key.
* `gpg --decrypt` — Decrypts GPG-encrypted files using the corresponding private key.
* `chattr +i` — Sets the immutable attribute on a file, preventing even the root user from modifying, deleting, or renaming it.
* `lsattr` — Lists file attributes on a Linux ext2/ext3/ext4 filesystem.
* `ufw enable` — Enables the Uncomplicated Firewall (UFW) to enforce firewall rules.
* `ufw allow` — Adds a rule to UFW to permit incoming traffic on specific ports or services.
* `ufw status` — Displays the current status and active rules of the UFW firewall.

# Commands Practiced on Day 20 (Checkpoint)

1. `grep` - Search text for matching patterns.
2. `grep -r` - Recursively search directories for patterns.
3. `grep -i` - Perform case-insensitive pattern searches.
4. `sort` - Order lines alphabetically.
5. `sort -n` - Order lines numerically.
6. `uniq` - Filter out adjacent duplicate lines.
7. `cut -d -f` - Extract specific fields based on a delimiter.
8. `awk` - Powerful pattern scanning and text processing language.
9. `sed` - Stream editor for filtering and transforming text.
10. `pipe chains (|)` - Connect the output of one command as input to another.

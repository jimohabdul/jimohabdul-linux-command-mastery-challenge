# Day 20: Text Processing & Pipes Checkpoint

## Overview
Day 20 marks the Phase 4 checkpoint of the 30-Day Linux Command Mastery Challenge. This lab integrates text searching, pattern matching, stream processing, and command piping into a unified data engineering workflow.

## Objectives
* Filter patterns using `grep` (recursive and case-insensitive options).
* Sort data alphanumerically and numerically (`sort`, `sort -n`).
* Extract columns and fields using `cut` and `awk`.
* Remove duplicate entries using `uniq`.
* Construct multi-stage pipeline chains (`|`) to analyze text logs efficiently.

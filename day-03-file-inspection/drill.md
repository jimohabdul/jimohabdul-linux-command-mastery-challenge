# Day 3 Drill: File Viewing & Inspection

## Objective
Practice inspecting file contents using various terminal viewing tools and filtering text with `grep`.

## Execution Steps
1. Created a sample log file with multiple lines of text.
2. Used `cat` to view the full file instantly.
3. Used `head` and `tail` to check the boundaries of the file.
4. Used `grep` to filter and find specific keywords inside the file.
5. Opened a larger file using `less` to practice scroll navigation.

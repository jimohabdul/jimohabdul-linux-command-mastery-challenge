# Day 03: Looking Inside Files
Phase 1 - File Navigation & Filesystem Mastery | Day 3 of 30

## Overview
Today I focused on learning how to inspect, read, and search through file contents directly from the Linux command line without needing external text editors.

## Commands Covered Today
See `commands.md` for full syntax breakdowns and practical use-cases covering `cat`, `less`, `head`, `tail`, and `grep`.

## What I Practiced
During today's practical drill, I practiced reading files of varying lengths, isolating specific lines using `head` and `tail`, tracking logs, and filtering out precise search terms using `grep`.

## What Surprised Me
How powerful `tail -f` is for monitoring live application logs in real-time—it's an indispensable tool for debugging and DevOps engineering.

# Day 8: Privilege Escalation & Identity

## Overview
Welcome to **Day 8** of the 30-Day Linux Command Mastery Challenge! This module focuses on managing superuser privileges, switching user security contexts, and inspecting system identity attributes.

## Objectives
* Master administrative command execution using `sudo`.
* Learn safe environment scoping and user switching (`su`, `su -`, `sudo -i`).
* Inspect effective user privileges and authorization policies (`sudo -l`, `id`, `whoami`).

## Files Included
* `commands.md`: Reference breakdown of the 10 core privilege and identity commands.
* `drill.md`: Step-by-step hands-on practice exercise and verification workflow.

# Day 18: Vim Fundamentals

## Overview
Day 18 introduces the foundational concepts of the Vim text editor. Essential for remote server administration where graphical interfaces are absent, Vim relies on modal editing—separating command inputs from text insertion.

## Objectives
* Launch and navigate files using the `vim` editor.
* Switch between Insert mode (`i`) and Command mode (`Esc`).
* Execute file save and exit commands (`:w`, `:wq`, `:q!`).
* Perform line editing tasks including deletion (`dd`), copying/pasting (`yy`, `p`), and state management (`u`, `Ctrl+r`).

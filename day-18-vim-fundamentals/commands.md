# Commands & Key Bindings Practiced on Day 18

1. `vim <file>` - Open a file inside the Vim editor.
2. `i` - Switch from Command mode to Insert mode.
3. `Esc` - Return from Insert mode to Command mode.
4. `:w` - Save changes to disk.
5. `:q` - Quit Vim.
6. `:wq` or `:x` - Save changes and quit.
7. `:q!` - Quit without saving (forced).
8. `dd` - Delete/cut the current line.
9. `yy / p` - Yank (copy) and paste lines.
10. `u / Ctrl+r` - Undo and redo text changes.

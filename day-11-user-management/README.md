# What I practiced
Created a new user account with a home directory and Bash shell, configured its password, added the account to a secondary group, renamed the username, and securely cleaned it up by removing both the account and its home directory.

# What surprised me
Seeing how `useradd` creates a barebones account by default unless you explicitly pass flags like `-m` for a home directory made me appreciate the safety and utility wrapper provided by `adduser`.

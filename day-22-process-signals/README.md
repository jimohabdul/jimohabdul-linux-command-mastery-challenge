# Day 22: Controlling Processes with Signals

## Overview
Day 22 of Phase 5 covers process lifecycle management, signal transmission (`SIGTERM`, `SIGKILL`, `SIGHUP`), active job control (`fg`, `bg`, `Ctrl+Z`), and session persistence using `nohup`.

## Objectives
* Terminate processes gracefully or forcefully using `kill`, `killall`, and `pkill`.
* Manage suspended and running terminal jobs via `jobs`, `fg`, and `bg`.
* Execute persistent background tasks that survive shell disconnections using `nohup`.

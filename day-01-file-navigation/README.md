# Day 1: Where Am I? Basic Orientation

## Objectives
* Understand absolute vs. relative paths and system orientation.
* Master basic filesystem navigation and directory creation.
* Learn to inspect hidden files and detailed file permissions.

## Commands Practiced
* 'pwd' - Print working directory
* 'ls', 'ls -l','ls -a', - List directory contents and hidden files
* 'cd', 'cd /', 'cd ..' - Change directory navigation.
* 'mkdir -p' - Create directory structures recursively.
* 'touch' - Initiates empty files.
* 'clear' - Clear terminal screen.

# Day 2 Drill: File Operations

## Objective
Create nested directories, generate files, copy items to backup locations, rename files, and safely clean up empty directories.

## Execution Steps
1. Created nested folders: `mkdir -p practice/2026/april`
2. Created empty files using `touch`.
3. Copied data using `cp -r`.
4. Renamed files using `mv`.
5. Cleaned up folders using `rm` and `rmdir`.

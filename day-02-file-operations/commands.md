# Day 2: Creating, Copying, Moving, and Deleting

## Commands Learned
- `mkdir` - Create a new directory (`mkdir -p` for nested structures).
- `touch` - Create empty files or update timestamps.
- `cp` - Copy files and directories (`cp -r` for recursive copy).
- `mv` - Move or rename files and directories.
- `rm` - Remove files (`rm -r` for recursive deletion).
- `rmdir` - Remove empty directories.

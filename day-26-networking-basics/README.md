# Day 26: Networking Basics

## Overview
Day 26 kicks off Phase 6 of the 30-Day Linux Command Mastery Challenge. This lab introduces core networking utilities used by Linux administrators to inspect interfaces, analyze routes, test connectivity, and audit active network listeners.

## Objectives
* Enumerate IP addresses and interfaces using `ip a`.
* Inspect routing tables and default gateways using `ip route`.
* Verify remote connectivity with `ping -c`.
* Fetch web data and headers using `curl` and `wget`.
* Audit listening ports and sockets using modern tools like `ss -tulnp`.

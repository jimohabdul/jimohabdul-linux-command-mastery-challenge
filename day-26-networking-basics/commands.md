# Commands Practiced on Day 26

1. `ip a` - Display network interfaces and IP addresses.
2. `ip route` - View network routing table and default gateway.
3. `ping -c` - Send ICMP packets with a specified count.
4. `curl` - Transfer data via URL.
5. `curl -I` - Fetch only HTTP response headers.
6. `wget` - Download web resources from the command line.
7. `netstat -tulnp` - List listening network sockets (legacy).
8. `ss -tulnp` - List listening sockets and PIDs (modern alternative).
9. `hostname` - Show system hostname.
10. `hostnamectl` - Comprehensive host configuration utility.

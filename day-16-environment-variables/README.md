# Day 16: Environment Variables

## Overview
Day 16 initiates Phase 4 of the 30-Day Linux Command Mastery Challenge, focusing on Linux shell environments. Understanding how environment variables and the `PATH` variable behave allows system administrators to configure sessions, manage application settings, and control binary execution paths.

## Objectives
* List and query environment variables using `printenv` and `env`.
* Create, modify, and delete custom session variables using `export` and `unset`.
* Manage and extend system execution directories using the `PATH` variable.
* Inspect global system configuration files like `/etc/environment`.

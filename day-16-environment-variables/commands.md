# Commands Practiced on Day 16

1. `printenv` - Print all or specific environment variables.
2. `printenv HOME` - Print the value of the HOME variable.
3. `echo $VAR` - Output the contents of a shell variable.
4. `export` - Set a custom environment variable for the current session.
5. `unset` - Delete an environment variable.
6. `env` - Print a complete list of exported environment variables.
7. `source` - Reload shell configuration files into the active session.
8. `echo $PATH` - Display current directories searched for executable binaries.
9. `export PATH=$PATH:...` - Append a new custom directory to the execution PATH.
10. `cat /etc/environment` - View system-wide environment variable settings.

# Commands Practiced on Day 25 (Checkpoint)

1. `ps aux | grep` - Filter processes.
2. `systemctl status` - Check service state.
3. `journalctl --since today` - Query recent logs.
4. `kill -0` - Check process liveness.
5. `uptime` - View load averages.
6. `free -h` - Inspect memory usage.
7. `vmstat` - Virtual memory metrics.
8. `iostat` - Storage I/O statistics.
9. `watch` - Periodic command execution.
10. `crontab -l` - List user cron schedules.

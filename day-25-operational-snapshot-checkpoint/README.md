# Day 25: Process & Service Checkpoint

## Overview
Day 25 marks the Phase 5 checkpoint of the 30-Day Linux Command Mastery Challenge. This lab integrates system visibility, health auditing, memory monitoring, and automated scheduling inspection into a unified operational snapshot.

## Objectives
* Audit system resource metrics (`uptime`, `free -h`, `vmstat`).
* Verify service runtimes and examine journal logs (`systemctl status`, `journalctl`).
* Inspect automated cron task schedules (`crontab -l`).

# Practice Drill: DNF/YUM & Alternative Installs

## Workflow Comparison (APT vs DNF):
* **Ubuntu/Debian (APT)**: Uses `apt update`, `apt install`, `apt remove`, and `dpkg -l`.
* **RHEL/CentOS/Amazon Linux (DNF/YUM)**: Uses `dnf update`, `dnf install`, `dnf remove`, and `rpm -qa`.

## Activities Covered:
1. Documented package syntax differences between Debian-based and Red Hat-based distributions.
2. Explored alternative installation vectors (`snap`, `pip`, `npm`, and local package installers).
3. Organized execution notes and screenshots into the repository evidence folder.

# Day 14: DNF/YUM & Alternative Installs

## Overview
Day 14 of the 30-Day Linux Command Mastery Challenge explores package management in Red Hat Enterprise Linux (RHEL), CentOS, and Amazon Linux environments using `dnf` and `yum`, alongside alternative installation methods like `snap`, PPA repositories (`add-apt-repository`), low-level `.rpm`/`.deb` packages (`dpkg -i`), and language-specific package managers (`pip` and `npm`).

## Objectives
* Understand package updates and installations using `dnf` and `yum`.
* Query installed packages in RHEL-based systems using `rpm -qa`.
* Explore alternative distribution channels (`snap`, custom PPAs).
* Install application packages using language runtimes (`pip`, `npm`).

# Commands Practiced on Day 14

1. `dnf update` - Refresh repositories and update packages on modern RHEL/Fedora/Amazon Linux.
2. `dnf install <package>` - Install a package using DNF.
3. `dnf remove <package>` - Remove a package using DNF.
4. `dnf search <keyword>` - Search for available packages in DNF repositories.
5. `yum install <package>` - Install a package using the legacy YUM manager.
6. `rpm -qa` - Query all installed RPM packages on Red Hat-based systems.
7. `snap install <package>` - Install containerized Snap application packages.
8. `add-apt-repository <repo>` - Add a Personal Package Archive (PPA) on Debian/Ubuntu systems.
9. `dpkg -i <file.deb>` - Install a local Debian package file directly.

10. `pip install <package>` / `npm install -g <package>` - Install packages via Python (pip) or Node.js (npm) package managers.

# Day 04: Securing the Filesystem - Permissions & Ownership
Phase 1 - File Navigation & Filesystem Mastery | Day 4 of 30

## Overview
Today I focused on understanding the core Linux security model, learning how user, group, and other permissions dictate who can read, write, or execute files on the system.

## Commands Covered Today
See `commands.md` for full syntax breakdowns and practical use-cases covering `ls -l`, `chmod`, `chown`, and `chgrp`.

## What I Practiced
During today's practical drill, I inspected file permission strings, adjusted access control using both symbolic and octal methods, and managed user/group ownership assignments.

## What Surprised Me
How numeric (octal) permissions like `755` and `644` translate directly into permission bits (rwx for user, group, and others)—it makes bulk permission adjustments much faster once memorized.

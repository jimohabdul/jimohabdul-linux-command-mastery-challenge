# Day 4 Drill: File Permissions & Ownership

## Objective
Practice checking file permissions, altering execution and read privileges with `chmod`, and managing user/group ownership.

## Execution Steps
1. Created a sample script file and checked its default permissions using `ls -l`.
2. Modified permissions to make the file executable using `chmod +x` and numeric notation (`chmod 755`).
3. Inspected user and group ownership details.
4. Tested changing ownership using `chown`.

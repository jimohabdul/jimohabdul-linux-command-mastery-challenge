# Practice Drill: Persisting Configuration

## Practice Sequence Executed:
1. **Persistent Editing**: Appended a permanent custom environment variable (`export CHALLENGE_DAY="Day17"`) and a shortcut alias (`alias update-sys='sudo apt update'`) to `~/.bashrc`.

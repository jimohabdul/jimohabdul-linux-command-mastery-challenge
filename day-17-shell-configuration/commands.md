# Commands Practiced on Day 17

1. `nano ~/.bashrc` - Open user shell configuration file for editing.
2. `source ~/.bashrc` - Reload changes in configuration files instantly.
3. `cat ~/.bash_profile` - Inspect login shell profile setups.
4. `sudo nano /etc/environment` - Modify global system environment variables.
5. `sudo nano /etc/bash.bashrc` - Modify global bash configuration rules.
6. `alias` - Create temporary or permanent shortcut commands.
7. `unalias` - Remove an active command alias.
8. `type` - Identify how a command is interpreted by the shell.
9. `which` - Locate the absolute binary file path for a command.
10. `whereis` - Locate binary, source, and manual files for a command.

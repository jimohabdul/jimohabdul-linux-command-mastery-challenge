# Commands Practiced on Day 13

1. `sudo apt update` - Refresh the local package index from repositories.
2. `sudo apt upgrade -y` - Upgrade all installed packages to their newer versions.
3. `sudo apt full-upgrade -y` - Perform a smart upgrade, handling changing dependencies with new packages.
4. `sudo apt install <package> -y` - Install a new package.
5. `sudo apt remove <package> -y` - Remove a package while keeping its configuration files.
6. `sudo apt purge <package> -y` - Completely remove a package along with its configuration files.
7. `sudo apt autoremove -y` - Remove automatically installed packages that are no longer needed.
8. `apt search <keyword>` - Search the package repositories for a specific keyword.
9. `apt show <package>` - Display detailed information about a package.
10. `dpkg -l` / `dpkg -L <package>` - List installed packages or files owned by a specific package.

# Commands & Key Bindings Practiced on Day 19

1. `gg / G` - Jump to top or bottom of the file.
2. `:10` - Jump directly to line number 10.
3. `/` - Search forward for a text pattern.
4. `?` - Search backward for a text pattern.

5. `n / N` - Jump to next or previous search match.
6. `:%s/old/new/g` - Replace every occurrence of a word globally across the file.
7. `dw` - Delete word.

8. `x` - Delete character.
9. `o / O` - Open new line below or above.
10. `ZZ` - Save and exit file quickly.

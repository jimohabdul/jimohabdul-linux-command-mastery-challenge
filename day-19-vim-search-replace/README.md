# Day 19: Vim Navigation & Search/Replace

## Overview
Day 19 advances Vim proficiency by introducing rapid document traversal, pattern matching, and global search-and-replace operations. These techniques allow engineers to inspect and refactor configuration files efficiently without using manual cursor movements.

## Objectives
* Jump across documents instantly using line commands (`gg`, `G`, `:line`).
* Search forward (`/`) and backward (`?`) for text patterns and iterate through matches (`n`, `N`).
* Perform global string replacements using substitution syntax (`:%s/old/new/g`).
* Execute advanced line adjustments and quick file exits (`o`, `O`, `ZZ`).

# Practice Drill: Vim Navigation & Search/Replace

## Practice Sequence Executed:
1. **Document Navigation**: Opened a multi-line test file, jumped straight to line 10 using `:10`, and used `gg` / `G` to traverse extremes.
2. **Pattern Matching**: Searched for specific keywords forward (`/`) and backward (`?`), utilizing `n` to cycle through matches.
3. **Global Refactoring**: Executed `:%s/old-word/new-word/g` to replace targeted occurrences across the entire file.
4. **Quick Save/Exit**: Persisted changes and exited using `ZZ`.

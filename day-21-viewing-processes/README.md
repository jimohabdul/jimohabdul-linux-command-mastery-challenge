# Day 21: Viewing Processes

## Overview
Day 21 marks the beginning of Phase 5 (Process & Service Management). This lab covers system visibility tools used by Linux administrators to track program execution, memory/CPU allocation, and port bindings.

## Objectives
* Enumerate processes using `ps aux` and `ps -ef`.
* Locate process IDs using `pgrep`.

* Inspect live metrics using `top`.
* Visualize parent-child process lineages with `pstree`.
* Map active network connections to specific processes using `lsof -i`.

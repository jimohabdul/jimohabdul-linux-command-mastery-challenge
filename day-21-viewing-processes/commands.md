# Commands Practiced on Day 21
1. `ps aux` - Detailed listing of all running processes.
2. `ps -ef` - Full format listing including parent process IDs (PPID).
3. `ps -u` - Filter process list by user owner.
4. `top` - Real-time dynamic view of running system tasks.
5. `htop` - Interactive process viewer with advanced usability.
6. `pgrep` - Filter and retrieve PIDs by process name.
7. `pstree` - Display process ancestry in tree format.
8. `lsof -i` - List open internet and network socket files.
9. `jobs` - View active shell background jobs.
10. `nice / renice` - Adjust process execution priority.

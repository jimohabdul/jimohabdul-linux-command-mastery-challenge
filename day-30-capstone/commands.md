# Commands Practiced in the Capstone

1. `ssh user@host` - Secure remote session execution.
2. `scp` - Secure file transmission.
3. `chown / chmod` - Ownership and permission security.
4. `systemctl restart` - Service lifecycle control.
5. `journalctl` - Log diagnostic verification.
6. `logger` - Operational audit logging.
7. `cron` - Task scheduling.
8. `grep / awk / sed` - Text filtering and parsing.
9. `find` - File search and cleanup.
10. `last / who` - Security session auditing.

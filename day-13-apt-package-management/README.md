# Day 13: APT Package Management

## Overview
Day 13 of the 30-Day Linux Command Mastery Challenge focuses on mastering the Advanced Package Tool (APT) and low-level package querying with `dpkg`. Managing software installation, updates, and clean removals is a foundational skill for Linux system administration and cloud engineering.

## Objectives
* Refresh local package lists and upgrade system packages.
* Install, remove, and completely purge software packages including configuration files.
* Clean up orphaned dependencies automatically.
* Query repositories and inspect installed package details.

# Day 3: File Viewing and Inspection

## Commands Covered Today
- `cat` - Concatenate and display the entire content of a file to the terminal.
- `less` - Open a file interactively, allowing page-by-page scrolling through large documents.
- `head` - Output the first part (default 10 lines) of files.
- `tail` - Output the last part of files (use `-f` to follow live log updates).
- `grep` - Search text using patterns and regular expressions.

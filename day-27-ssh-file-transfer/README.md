# Day 27: Remote Access & File Transfer

## Overview
Day 27 focuses on secure remote administration, key-based authentication, and encrypted file transfer mechanisms using `ssh`, `scp`, and `rsync`.

## Objectives
* Generate cryptographic key pairs (`ssh-keygen`).
* Deploy public keys for passwordless authentication (`ssh-copy-id`).
* Transfer files securely across networks (`scp`, `rsync`).

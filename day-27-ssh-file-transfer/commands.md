# Commands Practiced on Day 27

1. `ssh` - Secure shell remote connection.
2. `ssh -p` - Specify non-standard SSH port.
3. `ssh -i` - Use specific private identity key.
4. `ssh-keygen` - Create authentication keys.
5. `ssh-copy-id` - Copy public key to remote host.
6. `scp` - Secure file copy.
7. `sftp` - Interactive file transfer.
8. `rsync` - Synchronize files efficiently.
9. `~/.ssh/config` - Persistent SSH host profiles.
10. `sshd config hardening` - Secure server daemon settings.

# Commands Practiced on Day 29

1. `function_name() {}` - Custom Bash function block.
2. `$1, $2` - Positional arguments.
3. `$#, $@` - Argument counts and lists.
4. `$0` - Script filename reference.
5. `exit codes ($?)` - Command execution status.
6. `crontab syntax` - Time scheduling layout.
7. `cron scheduling` - Periodic task automation.
8. `nohup` - Persistent background execution.
9. `trap` - Signal and exit trap handling.
10. `logger` - System log message generator.

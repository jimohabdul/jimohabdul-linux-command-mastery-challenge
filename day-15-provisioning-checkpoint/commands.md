# Commands Practiced on Day 15 (Checkpoint)

1. `id <user>` - Display user identity, UID, GID, and group memberships.
2. `getent passwd <user>` - Query system account databases for user entries.
3. `useradd -m -G <groups> <user>` - Create a user account with a home directory and group attachments.
4. `passwd <user>` - Configure or update user authentication passwords.
5. `apt list --installed` - List all software packages currently installed.
6. `apt list --upgradable` - Check for pending package updates.
7. `apt update && apt install -y` - Chain repository updates and package installations.
8. `dpkg -l | grep` - Filter specific patterns out of installed package lists.
9. `apt autoremove` - Prune orphaned packages and clean storage.
10. `history` - Audit previously executed terminal commands.

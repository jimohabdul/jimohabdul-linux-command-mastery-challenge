# Day 15: Users & Packages Checkpoint

## Overview
Day 15 marks the midpoint checkpoint of the 30-Day Linux Command Mastery Challenge. This lab combines user management, account security provisioning, and software package lifecycle management into a comprehensive administrative workflow.

## Objectives
* Inspect user accounts and system identity databases (`id`, `getent`).
* Provision new user accounts with automated home directories and group memberships (`useradd`, `passwd`).
* Manage software tools via APT checks, chained installation commands, and package filtering (`dpkg | grep`).
* Perform system cleanup and review command execution audit trails (`history`).

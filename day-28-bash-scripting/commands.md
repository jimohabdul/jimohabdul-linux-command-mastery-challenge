# Commands Practiced on Day 28

1. `#!/bin/bash` - Shebang interpreter declaration.
2. `chmod +x` - Make script executable.
3. `./script.sh` - Execute local shell script.
4. `VAR=value` - Variable assignment.
5. `$()` - Command substitution.
6. `read -p` - User prompt input.
7. `if / fi` - Conditional logic blocks.
8. `-gt/-lt/-eq` - Numerical test operators.
9. `for loop` - Iteration construct.
10. `while loop` - Conditional loop construct.

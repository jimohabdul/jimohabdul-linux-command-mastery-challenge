# Commands Practiced on Day 23

1. `systemctl start` - Initialize a service.
2. `systemctl stop` - Terminate a running service.
3. `systemctl restart` - Cycle a service off and on.
4. `systemctl reload` - Apply config changes without restarting.
5. `systemctl enable` - Register service for boot startup.
6. `systemctl disable` - Unregister service from boot startup.
7. `systemctl enable --now` - Enable and start simultaneously.
8. `systemctl status` - Inspect detailed service health.
9. `systemctl is-active` - Check active execution state.
10. `systemctl is-enabled` - Check boot startup configuration.

# Day 23: Init Systems & systemctl Basics

## Overview
Day 23 focuses on modern Linux init systems and service management using `systemd`. Administrators use `systemctl` to control the runtime and boot-time states of background services.

## Objectives
* Control service execution states (`start`, `stop`, `restart`, `reload`).
* Configure boot-time behavior (`enable`, `disable`, `enable --now`).
* Inspect health, status, and configuration states (`status`, `is-active`, `is-enabled`).
